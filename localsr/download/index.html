What to know first

  • This is a beta. Features can still change, and some hardware is untested. The macOS v0.1.0-beta installer is Developer ID signed and notarized by Apple, and it notifies you when a newer beta is available. The older v0.0.11 Windows and Linux builds are unsigned — your system may warn or refuse to open them.
  • Phone and camera videos need FFmpeg. LocalSR only includes royalty-free video formats (AV1, VP9, FFV1 and more). To open H.264 or HEVC videos, or to export them, install FFmpeg yourself (for example brew install ffmpeg) and select it in the app under Advanced settings → Video. Photos work without it.
  • Results are reconstructions, not recovered truth. Upscaling models invent plausible detail. Edges, text, eyes, and skin can look convincing and still be wrong. Keep your originals — the app never overwrites them — and inspect results before you rely on or republish them.
  • Models have their own licenses. The app is MIT-licensed; the model files are not. Most allow personal use broadly, some allow commercial use with attribution, and a few are unclear. Read the model license table before downloading models or using results commercially.
  • Nothing leaves your computer. Media is processed locally. Model downloads contact their pinned source (GitHub / Hugging Face) and are hash-verified; there is no account, no analytics, no cloud inference.

More detail: the model guide explains every model in plain words, and the beta notes cover what ships and what is still in development.

Verify your file

Compare the SHA-256 digest of your download with the published checksum:

shasum -a 256 LocalSR-v0.1.0-beta-macOS-arm64.dmg

A matching checksum confirms the file is the listed release asset. The macOS v0.0.13 installer additionally carries a verifiable Apple notarization ticket.
