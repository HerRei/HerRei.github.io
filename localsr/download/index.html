On a Mac

Open the DMG and drag LocalSR onto the Applications folder. It is signed and notarized by Apple and updates itself. With Homebrew: brew install --cask herrei/tap/localsr

On Windows

Run the installer. It is not code-signed yet, so SmartScreen warns first: choose More info, then Run anyway. Download new versions from this page for now.

On Linux

Make the AppImage executable with chmod +x LocalSR-*.AppImage and run it. It needs glibc 2.39 or later, as in Ubuntu 24.04. Download new versions from this page for now.

What to know first

  • This is a beta. Features can still change, and some hardware is untested. The Mac build is the most tested. The Windows and Linux packages pass the codec policy and an automated test of the installed app, but have not had this release’s manual checks.
  • Graphics cards on Windows and Linux. The standard downloads run on the CPU. The GPU editions are listed under each platform: AMD ROCm (Linux), tested on a Radeon RX 9060 XT; NVIDIA CUDA (Windows and Linux) and DirectML (Windows), both untested: CUDA has not yet run on an NVIDIA card, and DirectML’s photo-denoising results can still differ from the CPU’s. CUDA needs a current NVIDIA driver; ROCm needs a supported Radeon and the amdgpu driver. The CUDA and ROCm editions are several gigabytes and come in parts.
  • Phone and camera videos open on a Mac. LocalSR itself includes only royalty-free video formats (AV1, VP9, FFV1 and more); on macOS it hands H.264, HEVC and AAC to the codecs that ship with the system, so iPhone and camera recordings open and export without extra software. Formats macOS cannot read (WMV, DivX, FLV) use an FFmpeg you install yourself; LocalSR finds it automatically and shows the install command when a file needs it. On Windows and Linux there are no such system codecs, so every patent-licensed format — H.264 and HEVC included — needs that installed FFmpeg; images and royalty-free video work without it.
  • Results are reconstructions, not recovered truth. Upscaling models invent plausible detail. Edges, text, eyes, and skin can look convincing and still be wrong. Keep your originals — the app never overwrites them — and inspect results before you rely on or republish them.
  • Models have their own licenses. The app is MIT-licensed; the model files are not. Every model LocalSR downloads for you is published under Apache-2.0, MIT, BSD-3-Clause or CC BY 4.0, which allow personal and commercial use (CC BY with attribution). Only the two optional face models, which you have to supply yourself, have unresolved rights. The model license table lists each one.
  • Your media stays on your computer. Photos and videos are processed locally and never uploaded; there is no account. Model downloads contact their pinned source (GitHub or Hugging Face) and are hash-verified. At launch the macOS app checks for updates and sends an anonymous count with that check: app version, platform and channel, with no identifiers. You can turn it off under Check for Updates in the app’s … menu. This website counts visits without cookies. The privacy page explains all of it.
  • No warranty. LocalSR is free software provided as is under the MIT license, without warranty of any kind. It is a beta: keep backups of anything that matters.

More detail: the user guide walks through the app, the model guide explains every model in plain words, and the beta notes cover what ships and what is still in development.

Downloads in parts

GitHub stores release files of up to 2 GB, and the NVIDIA and AMD editions are larger, so they come in parts. Each part is listed in SHA256SUMS.

Linux · AMD ROCm edition

Download all 5 parts into one folder, join them, check the result and make it executable:

cat LocalSR-v0.3.0-beta-Linux-ROCm-x86_64.AppImage.part-* > LocalSR-v0.3.0-beta-Linux-ROCm-x86_64.AppImage
sha256sum LocalSR-v0.3.0-beta-Linux-ROCm-x86_64.AppImage   # compare with SHA256SUMS
chmod +x LocalSR-v0.3.0-beta-Linux-ROCm-x86_64.AppImage

Check your file

Compare the SHA-256 of your download with the one in SHA256SUMS. A match confirms you have the published file.

macOS

shasum -a 256 LocalSR-*.dmg

The installer is also notarized by Apple. This should report accepted and Notarized Developer ID:

spctl -a -vv -t open --context context:primary-signature LocalSR-*.dmg

Windows, in PowerShell

Get-FileHash .\LocalSR-*.exe -Algorithm SHA256

Linux

sha256sum LocalSR-*.AppImage
