Add your own model

LocalSR v0.4 lets you run any compatible checkpoint directly from disk without waiting for a catalog release or copying files into Application Support.

Your file, your responsibility. LocalSR is MIT-licensed, but external model checkpoints carry their own licences and code-execution risks. Check a model’s rights on OpenModelDB or the author’s release page before downloading or publishing results.

  1. 1
    Check the licence and format first.

    Pick checkpoints whose licence covers what you need (for example MIT, BSD-3-Clause or CC BY), and prefer .safetensors files whenever offered.

  2. 2
    Open Your own file in LocalSR.

    Under Enhance → Model, press Change… (or ⇧⌘M / Ctrl+Shift+M), choose Your own file in the left sidebar, then click Choose checkpoint… to select the file anywhere on disk.

  3. 3
    Confirm pickle files explicitly if needed.

    .safetensors files run directly. PyTorch pickle checkpoints (.pth, .pt, .ckpt) can execute code inside the worker, so LocalSR keeps Upscale selected disabled until you tick Allow this pickle-based checkpoint.

  4. 4
    Run locally or stop cleanly.

    LocalSR supports 42 super-resolution architectures through Spandrel. Unsupported checkpoints stop immediately with Could not finish before changing any files.

Troubleshooting

Open or Reveal buttons are missing

Select a finished item in the Media or Outputs list. The buttons operate on the selected finished file.

Processing is very slow

Check under Advanced → Hardware that a GPU or Neural Engine is active instead of CPU. The standard Windows and Linux installers run on CPU unless you install a GPU edition. Try Quick, a smaller output scale, or run View → Performance and Diagnostics… to compare backends.

Stopped with an out-of-memory error

Enable Safe memory mode under Advanced, choose a lighter model such as SPAN instead of HAT-L, or close other memory-heavy applications.

A video file will not open

Legacy formats (and H.264/HEVC on Windows and Linux) use FFmpeg. Follow the install prompt LocalSR displays or choose FFmpeg via the app’s own file dialog.

The result looks plastic or invents wrong detail

Switch between Photo and Illustration, turn off unnecessary Fix first toggles, or compare models under which model for which photo. Super-resolution reconstructs plausible detail and cannot recover lost information reliably on tiny text or faces.

My custom checkpoint stopped with “Could not finish”

LocalSR uses Spandrel (42 supported super-resolution architectures). If a file is an unsupported architecture, damaged, or requires custom external scripts, LocalSR stops safely before writing anything. Check the author’s architecture notes and try a Spandrel-compatible release.

Support & bug reports

Report reproducible problems on GitHub Issues, or email hermes.reisner@gmail.com for anything private or security-related.

  • Include your app version, OS, CPU/GPU, model name, input dimensions and exact steps. For video, add format, duration and output size.
  • Copy diagnostics under View → Performance and Diagnostics… copies an app and hardware summary without filenames or images. Review reports before posting and never upload private images, settings databases or certificates.
  • Windows installers are unsigned, CUDA/Windows-NPU editions have not been verified on physical hardware, and SeedVR2, Edit, frame interpolation and HDR preservation remain experimental.

More context on volunteer project availability and full beta caveats lives on the support & limitations page and in KNOWN_LIMITATIONS.md.
