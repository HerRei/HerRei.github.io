03 Useful particulars

A few things
worth a closer look.

SR stands for super-resolution. It estimates a larger image from the pixels you already have. The result is a model’s interpretation, so the final judgment is yours.

2 · 3 · 4×Room to go larger.
Choose 2×, 3×, or 4× output dimensions. Large images are processed in overlapping tiles to work within available memory.
1×Restoration, at the same size.
Dedicated models can work on image noise, JPEG artifacts, or motion blur without enlarging the image.
ICCColor deserves care.
ICC-aware image output and support for common photo formats, including DNG input. Metadata handling depends on the format and settings.
LabsVideo is an experiment.
Local video upscaling and optional SeedVR2 models are available to explore. Next Preview notes: HDR with HAT, live tiles, and separate CPU/GPU scores. These preview changes are prepared separately from the current installer.

Before you begin

A few good questions.

Is it free?+

Yes. LocalSR is open source under the MIT license, with nothing to buy or sign up for. The models you download keep their own licenses; the model guide lists them.

Do my images leave my computer?+

The desktop app processes media locally. It has no cloud inference or analytics. You need an internet connection to download models; after that, those models run on your computer.

What does “beta” mean here?+

The macOS app is signed, notarized and ready for everyday testing, and it tells you when a newer beta is available. Windows and Linux betas, broader hardware testing and a public issue tracker are still in progress. The release notes spell out the current limitations.

Will it use my graphics card?+

The current macOS installer includes the Apple Silicon MPS backend. The older Windows and Linux alpha installers use CPU processing. GPU editions for Windows and Linux are future work.

Can it recover the original detail?+

Super-resolution estimates plausible detail from an image. It cannot guarantee the recovery of information that was lost, and results vary by source and model. Inspect small text, faces, and fine patterns carefully.

Are the models included?+

Most models download separately, when selected. The optional HAT-S and HAT-L Face variants require a verified user-supplied checkpoint; read about their results and availability. LocalSR checks curated downloads against their expected size and SHA-256 checksum. Model sizes and licenses vary; some commercial-use terms still need clarification. See the model notes before using a particular model commercially.
