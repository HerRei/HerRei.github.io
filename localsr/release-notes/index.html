LocalSR v0.0.13-alpha is an early desktop release for testing image restoration and super-resolution. Here is what ships, and what is still taking shape.

In this releaseYour platformStill in developmentModel notesSource and licensesChecksums

In this release

The desktop host uses Tauri and Svelte, with an isolated Python processing engine. It offers image enlargement at 2×, 3×, and 4×; denoising and deblurring; a media queue; model selection and verified downloads; and image preview and comparison.

JPEG, PNG, WebP, TIFF, and DNG input are supported. Video upscaling and optional SeedVR2 processing remain Labs / Experimental.

New in this release: legacy video imports — AVI, MPEG/VOB, WMV, camcorder MTS, FLV, 3GP and more — with automatic compatible playback copies, AAC audio conversion for MP4 export, interlacing and pixel-aspect correction, and conversion progress with cancellation. Original files are never modified.

Models are downloaded separately. The desktop app does not send media to a cloud inference service or collect analytics.

Choose the right installer

  • macOS 14+, Apple Silicon: a DMG with the MPS processing backend and CPU fallback. This build is Developer ID signed, notarized by Apple, and passed real image/video, cancellation and recovery checks on M1 Pro. It does not support Intel Macs.
  • Windows 10 / 11 and Linux: the v0.0.13 packages are still in preparation. Until they ship, the v0.0.11-alpha installers below remain available as unsigned test builds.

The v0.0.11-alpha builds are unsigned. Your operating system may warn or refuse to open them; only proceed if you accept that risk.

Still in development

This release is for early testing. Windows and Linux v0.0.13 packages, physical hardware acceptance across more devices, and a public issue tracker remain open work.

The packaged inference worker links FFmpeg with x264/x265; the worker combination is conveyed under GPL-3.0-or-later. The application source keeps its MIT notices. Complete source and build materials are published with the download (see below).

Video, de-flicker, SeedVR2, video comparison, and mixed image/video queues remain experimental. Optional video models can require multi-gigabyte downloads and substantial memory.

There is no active automatic-update feed for the direct macOS edition in this alpha.

Models have their own terms

Not sure which model does what? The model guide explains every model, its best use, and its license in plain words — including what to check before downloading or using results commercially.

LocalSR's application harness is MIT-licensed. Third-party code and model weights keep their own licenses. Selecting a model does not give every model the same commercial-use terms.

  • Quick Start: SPAN 4x NomosUni by Philip Hofmann, labelled CC BY 4.0. This is the model used in the website's worked example.
  • Best Quality and the RealPLKSR anime model: the upstream releases use a non-standard license identifier. Their intended commercial terms still need clarification.
  • Optional face restoration: HAT-S Face and HAT-L Face have unresolved checkpoint rights and require exact user-supplied files. See model results, trade-offs, and availability.

Curated model downloads are checked against pinned sizes and SHA-256 hashes. Unverified pickle or TorchScript checkpoints are blocked by default. Review the model's own terms before a commercial use or redistribution.

Source and licenses

Complete source and build materials for the macOS build are published alongside the installer: LocalSR-v0.0.13-alpha-macOS-sources.tar.gz, in the same download directory. A source mirror for the v0.0.11-alpha packages is published with them. Checksums for every published file are in each release directory's SHA256SUMS.

Verify your download

Compare the SHA-256 digest of your downloaded installer with the published checksum file.

On macOS:

shasum -a 256 LocalSR-v0.0.13-alpha-macOS-arm64.dmg

On Windows, in PowerShell:

Get-FileHash .\LocalSR-v0.0.11-alpha-Windows-x86_64.exe -Algorithm SHA256

On Linux:

sha256sum LocalSR-v0.0.11-alpha-Linux-x86_64.AppImage

A matching checksum confirms the file matches the listed release asset. The macOS v0.0.13 installer additionally carries a verifiable Apple notarization ticket.
