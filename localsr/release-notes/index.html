Release notes / 5 September 2026

A working alpha.
A work in progress.

LocalSR v0.0.12-alpha is an early desktop release for testing image restoration and super-resolution. Here is what ships, and what is still taking shape.

In this releaseYour platformStill in developmentModel notesChecksums

In this release

The current desktop host uses Tauri and Svelte, with an isolated Python processing engine. It offers image enlargement at 2×, 3×, and 4×; denoising and deblurring; a media queue; model selection and verified downloads; and image preview and comparison.

JPEG, PNG, WebP, TIFF, and DNG input are supported. Output and metadata behavior depend on the format and settings. Video upscaling and optional SeedVR2 processing remain Labs / Experimental.

Models are downloaded separately. The desktop app does not send media to a cloud inference service or collect analytics.

Choose the right installer

  • macOS 12+, Apple Silicon: a DMG with the MPS processing backend. This build does not support Intel Macs. It was cross-built and received static package inspection; physical Apple Silicon runtime acceptance is still outstanding.
  • Windows 10 / 11, x86-64: EXE installers with CUDA, DirectML, and CPU processing.
  • Linux, x86-64: AppImages with CUDA, AMD-ROCm, Intel-XPU, and CPU processing. Desktop and runtime compatibility can vary between distributions.

Windows and Linux packages have automated install/startup checks. Those checks do not replace physical testing on every device.

These are unsigned test builds. The macOS bundle has an ad-hoc seal, but no production Developer ID signature or notarization. The Windows installer has no Authenticode signature. Your operating system may warn or refuse to open the application.

Still in development

This release is for early testing. Production signing, maintained native runtimes, physical hardware acceptance, and broader compatibility remain prerequisites for a beta release.

The alpha still includes older runtime dependencies with known security advisories. Runtime updates and the relevant upstream platform migrations remain open work; this package is not a production-ready beta.

Video, de-flicker, SeedVR2, video comparison, and mixed image/video queues remain experimental. Optional video models can require multi-gigabyte downloads and substantial memory.

The new desktop host uses a separate application identity and state directory, so it can coexist with the earlier Slint application. There is no supported Homebrew installation route for this alpha.

Models have their own terms

LocalSR's application harness is MIT-licensed. Third-party code and model weights keep their own licenses. Selecting a model does not give every model the same commercial-use terms.

  • Quick Start: SPAN 4x NomosUni by Philip Hofmann, labelled CC BY 4.0. This is the model used in the website's worked example.
  • Best Quality and the RealPLKSR anime model: the upstream releases use a non-standard license identifier. Their intended commercial terms still need clarification.
  • Optional face restoration: checkpoint rights remain unresolved. That checkpoint is excluded from trusted automatic downloads.

Curated model downloads are checked against pinned sizes and SHA-256 hashes. Unverified pickle or TorchScript checkpoints are blocked by default. Review the model's own terms before a commercial use or redistribution.

Verify your download

Compare the SHA-256 digest of your downloaded installer with the published checksum file. The website's checksum list is taken from the existing v0.0.12-alpha release.

On macOS:

shasum -a 256 LocalSR-v0.0.12-alpha-macOS-arm64.dmg

On Windows, in PowerShell:

Get-FileHash .\LocalSR-v0.0.12-alpha-Windows-x86_64.exe -Algorithm SHA256

On Linux:

sha256sum LocalSR-v0.0.12-alpha-Linux-x86_64.AppImage

A matching checksum confirms the file matches the listed release asset. It does not replace an operating-system signature or the development checks described above.
